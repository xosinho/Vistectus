IMAGES USED BY index.html
=========================

One portrait per faction, displayed at 3:4. Save at roughly 900 x 1200 px;
JPEG at quality ~80 is ample, and keeps the page light.

Each faction's <img> in index.html names the file it expects, e.g.
images/faction-one.jpg. When you give a faction its real name, rename its
id and its image file to match, and use the same spelling in both.

Until a file exists, its frame shows a dark gradient plus the alt text,
at the right size, so the page never looks broken.

Filenames must match exactly: the live host is case-sensitive even though
Windows is not.
