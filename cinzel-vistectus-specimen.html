THE MATCH

Your wordmark is inscriptional Roman — the Trajan tradition of carved capitals: tall proportions, a heavy stroke contrast between thick stems and thin serifs, and serifs that flare to a point rather than sitting square.

Cinzel reproduces those letterforms exactly. What it cannot carry is the stone weathering and metallic lighting — those live in your logo image or in CSS effects like the gradient fill above, not in the font itself. Set flat, the shapes are the same lineage.

DROP IT INTO STYLE.CSS

The simplest route for your GitHub Pages site — one import line, then apply the family to your headings.

/* top of style.css */
@import url('https://fonts.googleapis.com/css2?family=Cinzel:wght@400;600;700&display=swap');

/* wordmark / page title */
.wordmark {
  font-family: 'Cinzel', serif;
  font-weight: 700;
  letter-spacing: 0.06em;
}

/* section headings */
h1, h2, h3 {
  font-family: 'Cinzel', serif;
  font-weight: 600;
  letter-spacing: 0.04em;
}

/* tagline — same face, light and wide */
.tagline {
  font-family: 'Cinzel', serif;
  font-weight: 400;
  letter-spacing: 0.4em;
}

For offline builds, faster loads, or if you'd rather not call Google, self-host instead: download the family from the Cinzel page on Google Fonts (OFL — free to bundle), drop the .woff2 files in the repo, and swap the @import for local @font-face rules. Either way it publishes on your next git push.
